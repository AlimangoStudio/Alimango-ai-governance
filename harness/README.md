# Reference Harnesses

Harnesses are executable or procedural mechanisms that apply the policies in `.agents/`.

- `audit-kernel.md` — immutable-style review input/output contract
- `capability-doctor.md` — environment/tool capability preflight
- `context-compiler.md` — bounded authority-aware context assembly
- `skill-tdd.md` — tests for reusable agent skills
- `external-adoption.md` — safe evaluation of third-party ideas
- `parallel-work.md` — bounded multi-agent coordination

These are public reference designs, not Alimango production runtime components.
