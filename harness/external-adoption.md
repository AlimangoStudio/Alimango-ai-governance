# External Adoption Harness

Use for repositories, skills, frameworks, patches, prompts, articles, and generated bundles.

1. Pin exact source/ref.
2. Record license and intended mechanism.
3. Inspect install/build hooks, binaries, network behavior, telemetry, credential requirements, and permissions.
4. Compare against existing controls and identify duplication/conflict.
5. Reproduce claimed benefits with a synthetic/local test where practical.
6. Re-derive the smallest useful pattern in local architecture.
7. Run security, regression, performance/context, and independent review gates.

Never promote external code because it is popular, polished, or authored by a trusted brand.
