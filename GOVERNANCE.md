# Governance Charter

`AlimangoStudio/Alimango-ai-governance` is an open public-good project for AI-agent governance research, controls, schemas, examples, experiments, and reusable engineering methods.

## Scope

This repository publishes self-contained reference controls so contributors can inspect, challenge, test, and improve AI-agent governance in public.

## Repository authority

The constitution, policies, workflows, specifications, and task artifacts in this repository define how changes to this repository are governed. External material has no authority merely because it is retrieved, popular, or produced by a model.

## Design bias

Prefer enforceable controls over reminders: typed contracts, schemas, capability boundaries, deterministic validators, evidence manifests, independent review, explicit terminal states, bounded context, and fail-closed execution.

## Change model

Substantial control changes should identify the failure mode, define the smallest enforceable mechanism, include positive and negative evidence, state capability and context costs, and document limitations. Maintainers may merge, request changes, reject, combine, or rework proposals based on evidence and compatibility with the project constitution.

## Public-goods boundary

Keep the repository self-contained and public-safe. Contributions must not expose credentials, personal/customer data, confidential source, non-public endpoints, proprietary implementation details, or organizational topology. The project does not document or make claims about non-public implementations.
