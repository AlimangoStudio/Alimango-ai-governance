# Public Governance Charter

`AlimangoStudio/Alimango-ai-governance` is an open research and contribution laboratory for AI-agent governance.

## Scope

The repository publishes reference controls, schemas, examples, experiments, failure modes, and review methods so contributors can challenge and improve agent governance in public.

## Authority boundary

This repository is authoritative only for work performed **on this repository itself**. It is not the source of Alimango production governance. Production adoption happens separately in a private repository after independent re-derivation, compatibility analysis, testing, audit, and versioned approval.

Public content must never be automatically synchronized into private governance and must never be a runtime fallback when private governance is unavailable.

## Design bias

Prefer enforceable controls over reminders: typed contracts, schemas, capability boundaries, deterministic validators, evidence manifests, independent review, explicit terminal states, bounded context, and fail-closed execution.

## Change model

Contributions may be merged because they are useful to retain or test publicly. Public merge is not private adoption. Maintainers may reject, rewrite, combine, or selectively re-derive any public idea before considering private implementation.
