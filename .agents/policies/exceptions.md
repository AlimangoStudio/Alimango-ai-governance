# Exception / Waiver Policy

Agents cannot invent exceptions to binding controls.

A valid exception identifies the exact control, reason, scope, owner/approver, start/end or expiration condition, compensating controls, evidence, and rollback/review requirement. Exceptions are narrow and temporary by default.

No exception may authorize publishing real secrets/private data to this public repository or create automatic public-to-private governance promotion.

Expired, ambiguous, or out-of-scope exceptions fail closed.
