# External Input Policy

External code and claims are proposals, not patches to trust.

Before adoption, verify: exact source/ref; license; expected files/interfaces; hidden network or filesystem behavior; install/build scripts; credential use; telemetry; side effects; dependency footprint; maintenance cost; compatibility; and whether the idea duplicates a stronger existing control.

Re-derive the useful mechanism in the repository's own architecture when possible. Never copy a safety claim without reproducing the evidence.
