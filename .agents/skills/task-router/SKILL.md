# Task Router

Route work before implementation.

Classify: research vs behavior change; risk R0–R4; affected control domains; required capabilities; required workflows; likely independent review lanes; context sources; and expected evidence.

Default mappings: security/permissions/supply-chain → adversarial review; cross-cutting changes → blast-radius proof; side effects → action governance; behavior changes → Spec Kit; completion claims → Done-When/Proof + Unlazy + convergence.

Do not route by filename alone; route by behavioral impact.
