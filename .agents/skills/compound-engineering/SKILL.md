# Compound Engineering

Treat solved problems as reusable engineering assets rather than one-off chat history.

After a task converges, identify reusable controls, tests, schemas, failure cases, runbooks, or context modules that reduce future work. Promote only the generic mechanism; keep project-specific facts in project overlays.

Do not accumulate duplicate prose. Prefer one canonical control plus adapters/references. Version breaking control changes and document migration impact.
