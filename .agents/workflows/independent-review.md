# Independent Review Workflow

For material risk, assign a reviewer that did not implement the change when practical.

Reviewer posture is read-only by default. Review requirements, diff/behavior, capability changes, trust boundaries, failure paths, regression evidence, supply-chain effects, context policy, and completion claims.

Findings include severity, evidence, affected requirement, and recommended disposition. Verdict is `accept`, `changes_required`, or `blocked`. Reviewers do not silently fix their own findings and then self-approve.
