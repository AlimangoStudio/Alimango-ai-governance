# Role Profiles

Roles constrain focus and capabilities; they do not create new authority.

- **researcher:** read-oriented evidence gathering; no implementation side effects by default.
- **implementer:** scoped repository changes; cannot self-approve material risk.
- **reviewer:** read-only independent correctness/evidence challenge.
- **security-reviewer:** read-only adversarial security/capability/context review.
- **release-coordinator:** reconciles evidence and delivery state; does not bypass deployment/approval gates.

Delegation must specify role, task, context, budget, capabilities, and expected output.
