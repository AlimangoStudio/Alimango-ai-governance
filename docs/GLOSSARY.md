# Glossary

**Authority** — the ordered source of binding instructions.  
**Capability** — a permission class such as repo write, secret read, deploy, or destructive action.  
**Control plane** — mechanisms that govern agent context, permissions, execution, evidence, and completion.  
**Evidence** — revision-relevant proof supporting a requirement or state claim.  
**Fail closed** — deny/block/degrade safely when a required control cannot be verified.  
**Spec Kit** — specification-to-convergence workflow for behavior changes.  
**Unlazy** — final anti-shortcut completion gate.  
**Convergence** — reconciliation of contract, implementation, evidence, findings, and terminal state.  
**RAG/CAG** — retrieval-augmented and cache-augmented context patterns.  
**Independent review** — challenge performed without relying on the implementer's self-assessment.  
**Public lab** — this advisory repository; never production authority.
