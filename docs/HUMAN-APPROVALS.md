# Human Approval Model

Human approval is a capability token for a specific action, not a general endorsement of an agent.

An approval record should identify: requested action, target, scope, data class, material side effects, reversibility, relevant evidence, and expiration/context when appropriate.

Typical approval-required classes include production deployment, destructive/irreversible operations, secret/credential access beyond established automation, identity/security changes, migrations over protected data, financial actions, and publication of sensitive material.

Approval must not be inferred from silence, old approval for another target, tool availability, or a contributor's role.
