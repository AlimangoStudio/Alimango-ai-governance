# Control Taxonomy

## Preventive controls
Authority order, least capability, allowlists, typed tool contracts, secret isolation, source pinning, context sensitivity labels.

## Detective controls
Static validation, negative tests, secret scans, telemetry, audit logs, policy-drift checks, dependency review.

## Corrective controls
Rollback, cancellation, retry bounds, finding disposition, migration repair, policy upgrade manifests.

## Evidence controls
Done-When gates, content hashes, test results, review verdicts, postcondition checks, live verification when applicable.

## Human controls
Approval for material side effects, exception review, security escalation, private adoption decision.

## Meta-controls
Constitution, control registry, versioning, convergence, Unlazy, independent review, and protection against a control editing itself without equivalent review.
