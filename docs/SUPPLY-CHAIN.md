# AI Governance Supply Chain

The supply chain includes packages, actions, containers, models, prompt/skill repositories, generated patches, binaries, datasets, MCP/tool servers, and reference implementations.

Before material adoption, identify exact source/ref, license, maintainer/publisher, install hooks, binaries, network destinations, telemetry, credential needs, transitive dependencies, requested permissions, update mechanism, and rollback path.

Prefer immutable pins for high-risk use. Public upstream changes are candidates for review, never automatic policy updates.
