# Good First Contributions

Useful first contributions are small improvements that are easy to verify and do not require access to private Alimango systems.

Examples:

- a synthetic test case demonstrating a common agent failure mode,
- a proposal for a clearer capability/permission schema,
- a lightweight validator for malformed governance metadata,
- a reproducible context-budget or source-freshness experiment,
- improvements to issue/PR templates,
- a security review checklist for a narrowly defined agent action,
- a comparison of two public governance patterns with explicit trade-offs.

Avoid first contributions that attempt to replace the entire governance architecture or introduce a large dependency stack without a demonstrated gap.
