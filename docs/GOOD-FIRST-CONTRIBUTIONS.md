# Good First Contributions

Useful first contributions are small improvements that are easy to verify and rely only on the public repository and public-safe synthetic fixtures.

Examples:

- a synthetic test case demonstrating a common agent failure mode,
- a proposal for a clearer capability or permission schema,
- a lightweight validator for malformed governance metadata,
- a reproducible context-budget or source-freshness experiment,
- improvements to issue or PR templates,
- a security review checklist for a narrowly defined agent action,
- a comparison of two public governance patterns with explicit trade-offs.

Avoid first contributions that attempt to replace the entire governance architecture, introduce a large dependency stack without a demonstrated gap, or require confidential project context.
