# Public Scope

This repository is maintained as self-contained public goods for AI-agent governance.

## Publishable material

Public artifacts may include:

- generic governance controls and policies;
- synthetic examples and test fixtures;
- public-source references with provenance and license information;
- schemas, validators, workflows, benchmarks, and experiment protocols;
- portable integration patterns that use placeholder organizations, projects, endpoints, identities, and data.

## Non-public material

Do not publish or infer:

- credentials, secrets, keys, tokens, or authentication material;
- personal/customer data;
- confidential or proprietary source code;
- non-public repository or project names;
- real internal endpoints, hosts, infrastructure, or deployment topology;
- customer environments or operational identifiers;
- organizational relationships that are not already intentionally public.

## Self-contained documentation

A public document should be understandable without knowing anything about the maintainer's other work. Examples must use synthetic names and targets. Architecture diagrams should describe the reference design itself, not an organization's implementation map.

## External sources

External public sources are inputs, not authority by default. Record provenance, exact version/ref where relevant, license, expected behavior, permissions, side effects, and known limitations.

## Adoption

Anyone may study, fork, adapt, vendor, or pin the reference under its license. Adopters are responsible for deciding how the controls fit their own environment. This repository does not document, enumerate, or make claims about adopter implementations.
