# Governance Experiment Protocol

A useful public experiment states a hypothesis, failure mode, control under test, baseline, synthetic fixture, expected observable result, resource cost, limitations, and reproduction steps.

Prefer experiments that compare mechanisms rather than models: e.g. prompt warning vs typed capability contract, whole-repo context vs bounded context compile, self-review vs independent review.

Do not use private data, credentials, live customer systems, or destructive external targets. Results in this lab are evidence for discussion, not automatic private adoption.
