# Support and Questions

Use the repository's public collaboration surfaces according to the type of question:

- **Design question or early idea:** start a GitHub Discussion.
- **Concrete governance gap:** open a Governance Improvement issue.
- **Reproducible problem in this public repository:** open a Bug Report.
- **Security vulnerability:** follow `SECURITY.md`; do not publish secrets or exploit details in a normal issue.
- **Reviewable experiment/control:** open a focused pull request.

This project does not provide support for private Alimango systems through the public repository. Do not post private source, infrastructure details, credentials, customer data, or production incidents here.
