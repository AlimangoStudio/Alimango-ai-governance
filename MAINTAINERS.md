# Maintainer Notes

The maintainer goal is to keep this repository useful as an open idea base without allowing it to become a shadow source of Alimango production governance.

- Prefer squash merges for focused public PRs.
- Do not enable automatic promotion into private systems.
- Close unsafe, redundant, unverifiable, or low-value PRs without preserving backwards compatibility for experimental public ideas.
- Keep private project details out of review discussion.
- When an idea appears valuable for private use, open a separate private evaluation rather than copying the public branch wholesale.
